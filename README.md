# Medical Store Stock Alert

A smart inventory system for medical stores to track stock, expiry dates and low-stock alerts.

### Problem
Medical stores face losses due to manual tracking - medicines expire or go out of stock unnoticed.

### Solution
This system provides a live dashboard with auto alerts (Red for Expired, Yellow for Low Stock) to prevent loss.

### Features
- Add / Update / Delete Medicines
- Live Low-Stock Counter
- Expiry Alert (30 days before expiry)
- Search & Filter
- Color-coded Status

### Tech Stack
Java (Spring Boot) | JavaScript | REST API | MySQL / JSON

### How to Run
1. mvn clean
2. mvn spring-boot:run
3. Open http://localhost:8000
